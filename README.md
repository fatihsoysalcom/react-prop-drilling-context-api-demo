# React Prop Drilling Context API Demo

This example demonstrates React's 'prop drilling' problem and how to solve it using the Context API. It shows a component hierarchy where data is passed through unnecessary intermediate components, and then refactors the same hierarchy to use Context API for direct data access, improving code clarity and maintainability.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
